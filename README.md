# 🛵 Rapido Clone

A front-end clone of the **Rapido Bike Taxi App**, built using **HTML**, **CSS**, and **JavaScript**.  
This project replicates the design, structure, and responsiveness of the official Rapido website/app interface.

---

## 📖 Project Overview

The **Rapido Clone** project is a web-based replica of the popular bike taxi booking platform **Rapido**.  
It showcases my front-end development skills and understanding of responsive UI/UX layouts.  

The clone includes essential sections such as:
- Homepage with Hero Banner
- Services Overview
- Download App Section
- Driver/Customer Registration Section
- Footer with Contact and Social Links

---

## ⚙️ Tech Stack

| Component | Technology |
|------------|-------------|
| **Frontend** | HTML, CSS, JavaScript |
| **Design** | Flexbox, CSS Grid |
| **Icons & Assets** | Font Awesome, Rapido official assets |
| **Deployment** | Netlify / GitHub Pages |

---

## ✨ Features

- 🎨 **Pixel-Perfect UI** similar to Rapido's homepage.  
- 📱 **Fully Responsive Design** for both mobile and desktop screens.  
- 🚴 **Interactive Sections** with hover effects and animations.  
- 🧭 **Navigation Bar** with smooth scrolling to sections.  
- 🧑‍💼 **Partner/Customer Sections** with call-to-action buttons.  
- 📄 **Footer with Social Media Links** and Contact Info.
